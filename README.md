# Sumo
Un proyecto de código abierto (no soy envidioso) de un sumo muy básico hecho con ESP32 para ser controlado por Bluetooth con RemoteXY

 <img width="801" height="672" alt="imagen" src="https://github.com/user-attachments/assets/373a88f7-88c4-4edd-917e-51c27095df8c" />

## Que es??
Actualmente esta en etapa de desarrollo y con materiales que tengo en mi casa, una impresión en 3D hecha por mi en Onshape y 5 horas de tiempo libre en vacaciones, es un robot de combate básico que empuja a un oponente fuera de el _dohyo_ para ganar el combate, puede ser controlado remotamente con RemoteXY o se puede controlar solo con el sensor ultrasonico

## Como funciona?
Solo con dos motores amarillos, un sensor ultrasonico y un ESP32 se mueve a los lados, no esta planeado para tener una fuente de alimentación en este momento porque es una beta
